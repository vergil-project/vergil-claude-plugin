# Release 2.1.78 (2026-11-18)

## Documentation

- **handle check_cancelled and failed: cancelled by re-running the cancelled checks (#1161)**
  vergil-tooling#4692 adds a reason for a required check cancelled with no newer run to replace it, and counts a check cancelled by a superseding run as pending. pr-watch now re-runs such checks with no code change, and says a check_failed never names a superseded run. Ref #1159.

## Features

- **check the TypeScript audit on develop before a change; allow a dated exception (#1162)**
  Adds a TypeScript-only learned ready-to-start condition: run the audit stage on develop first, and for a high advisory with no patched release file a tracking issue and add a dated .npm-audit-exceptions entry as its own commit. The change template names that entry as the one allowed exception to its no-suppressed-gate rule. Ref #1160.
- **ask the human before filing an audit-exception tracking issue (#1165)**
  The TypeScript audit condition no longer treats the ruling on vergil-project/.github#1218 as standing approval: the run lists the advisory under Awaiting a ruling and files the tracking issue and adds the exception only once the human approves. Ref #1164.
