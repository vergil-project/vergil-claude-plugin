
# Release 2.1.65 (2026-11-12)

## Features

- **batch independent ready tasks and resume batches (#1021)**
- **resume the last issue of a collapsed batch from the batch worktree (#1023)**
* feat(issue-implement): resume the last issue of a collapsed batch from the batch worktree

A batch left with one issue keeps its work in the batch worktree and branch. Later runs find that worktree from the issue's commit subject on a feature/<M>-batch-* branch, so Preflight step 6, a batch start and epic-implement's dispatch and re-entry no longer depend on a remembered worktree name. Ref vergil-project/vergil-claude-plugin#1022.

* fix(issue-implement): find a collapsed batch's worktree before its merge review starts

Preflight step 6 now runs the collapsed-batch lookup when the task has neither a marker nor a merge-review directory, so a remaining issue with commits on the batch branch is not given a new worktree. Merge review R1. Ref vergil-project/vergil-claude-plugin#1022.
