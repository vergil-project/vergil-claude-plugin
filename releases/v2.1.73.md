
# Release 2.1.73 (2026-11-16)

## Bug fixes

- **remove the batch worktree when an extraction leaves it with no work (#1098)**
When an extraction resets the batch worktree to base_sha and leaves fewer than two issues, the issue left has no commit, so the collapsed-batch lookup can never find the worktree. The extraction now checks that the worktree holds no edit and no commit, removes it and its branch without --force, and the remaining issue runs as an ordinary single issue in its own worktree. Ref vergil-project/vergil-claude-plugin#1038.

- **read the reviewer's reply from the captured result, never the escaped completion notice (#1099)**
* fix(merge-review): read the reviewer's reply from the captured result, never the escaped completion notice

The subagent completion notice escapes &, < and > as HTML entities, while the capture hook's last_assistant_message is the reviewer's own text, so result-<step>.md is already stored as received. The skill now says so, reads the reply (security details included) only from result-<step>.md, and forbids decoding or fixing either copy by hand. The capture hook test's reply now holds markup characters and entity-like text that must survive byte for byte. Ref vergil-project/vergil-claude-plugin#1039.

* fix(merge-review): clear the shellcheck finding in the capture hook test's reply

Ref vergil-project/vergil-claude-plugin#1039.
