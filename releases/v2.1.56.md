## Features

- **allow Write and Edit anywhere in the main clone's ignored build/ (#896)**
* feat(hooks): allow Write and Edit anywhere in the main clone's build/

The worktree write hook now allows any target that normalises to a path inside the main clone's ignored build/ scratch directory, not only build/.vergil-state/, matching the worktree convention's build/ exception. Paths that leave build/ through .. or a symlink, or through a build that is itself a symlink, are still denied. Tests, the hooks page, the README, the design spec and doctrine section 1.5 follow; the state-directory checks are unchanged.

* fix(hooks): allow only git-ignored paths under the main clone's build/

A Write or Edit under build/ is allowed only when git check-ignore reports the target ignored; a non-zero result or a git failure denies it. Adds tests for a build/ the repo does not ignore and for a tracked file under build/, and notes the rule on the hooks page and in the design spec.

* fix(hooks): isolate the write-guard tests from user git config and cover a failed ignore check

The hook's tests now run git with no global or system config and a scratch HOME, so only each scratch repo's .gitignore decides what is ignored, and add a row where git check-ignore fails, asserting a deny for that reason. The hook's comment and deny message say plainly that git does not report the path ignored. Doctrine section 1.5 and the design spec's denial and edge-case lists now state the ignored-only rule for build/.

* test(hooks): assert the reason on the write-guard's build/ deny rows

The rows for a build/ that is not ignored and a tracked file under build/ now also check the deny reason, so each passes only on the deny it is meant to exercise.
