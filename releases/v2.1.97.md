# Release 2.1.97 (2026-11-25)

## Bug fixes

- **screen every reviewer reply for security content before posting it**
  The merge review published a reviewer reply whole whenever it flagged no security finding, so a description of a security fix ruled outside the review, or a security-class remark below the bar, could reach the public step comment. Every result is now screened against doctrine section 1.6 before its step comment is built: a qualifying finding becomes a security finding, and any other security-class text withholds the reply. The reviewer prompt now names both cases. Ref #1264
- **write security details on resume after the screen**
  Merge review R1: the resume path ran the screen without the security-details step. Ref #1264
