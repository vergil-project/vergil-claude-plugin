
# Release 2.1.51 (2026-10-29)

## Documentation

- **move the marketplace definition to user-level settings (#810)**
* docs(install): move the marketplace definition to user-level settings

The install instructions told consumers to put extraKnownMarketplaces in the repo's .claude/settings.json. Under the Claude config ownership model the marketplace definition and plugin enable live in ~/.claude/settings.json; a managed repo's file equals the vergil-tooling template and only enables vergil@vergil-marketplace. Link the ownership model and Consuming Repo Setup. Refs vergil-project/vergil-claude-plugin#809.

* docs(install): say to merge the entries into existing user settings

The user settings file usually exists already, so tell readers to merge the marketplace and enable entries into existing extraKnownMarketplaces and enabledPlugins objects instead of adding second copies of those keys. Refs vergil-project/vergil-claude-plugin#809.

- **make the mode 1 reviewer's security failure signal unambiguous (#815)**
Replace the mode 1 'security hold' failure signal with a SECURITY-CHECK-FAILED line, require the Security: line in its exact format with no annotations, and reword the routing directive so it no longer uses the word hold. Record the change in the template's history in section 2.3 and key the section 2.4 checks on the token and the exact line. Ref #812

- **brief the brainstorm from the planning issue and never skip it implicitly (#816)**
Step 1 now passes what the planning issue settles into the brainstorm as given context, treats skip-the-questions instructions as fewer questions rather than no brainstorm, and skips the stage only on an explicit request, confirmed once and recorded with the human's reason. Ref #814
