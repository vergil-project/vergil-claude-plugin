
# Release 2.1.71 (2026-11-14)

## Bug fixes

- **warn only on bare container-tool calls and drop the host-tool deny (#1078)**
enforce-host-container-split now warns only when a container-only tool is invoked bare on the host, naming the wrapped form for an ad hoc run and the full vrg-validate still required before handoff; the wrapped form passes silently. The deny on a host tool wrapped in vrg-container-run is removed along with HOST_TOOLS, which had no other consumer: such a run fails on its own and the full vrg-validate is the backstop. Tests, the hooks reference and the README table follow. Ref #993.
