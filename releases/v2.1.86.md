## Documentation

- **ask no confirmation for an absent state directory in a session's first round (#1119)**
  Split the first-round state-directory rule into absent and present cases, and make the same split where it is restated: doctrine 1.10 and 2.4, the upstream-report bullet and epic-create design review step 1.
- **mention the ad-hoc to planning route now that vrg-intake-route allows it (#1133)**
  vergil-tooling#4598 lets vrg-intake-route take an ad-hoc item to planning. epic-create pulls an ad-hoc issue into planning instead of refusing it, issue-implement offers the route alongside a split for an ad-hoc task too big for one PR, and epic-review's revive row notes that such an item no longer detours through deferred.
- **put agent-refused deploy steps under Human-run steps (#1177)**
  A deployment task that listed vrg-host plugins and vrg-vm update --all as agent-safe steps stopped issue-deploy until the human ran them. epic-create now says a step that refuses the agent identity goes in the scaffold's Human-run steps section, and names the common ones.
- **run the TypeScript rollback's npm commands in the container (#1186)**
  The host's npm can be older than the ts-node image's, and an older npm drops lockfile fields it does not know, so a host-run rollback rewrote unrelated package-lock.json entries. Run both npm commands through vrg-container-run, the npm CI and vrg-update-deps use, and say why. Ref vergil-project/vergil-claude-plugin#1186
- **render the header's Span as a table of windows with readable dates and elapsed time (#1257)**
  The retrospective header's Span line packed six ISO-8601 timestamps into prose and left the reader to work out the durations. The skill now specifies the header and its Span: a table with one row each for the whole epic, planning and implementation, each with a readable UTC start and end and the elapsed time computed from the queried times. Ref vergil-project/vergil-claude-plugin#1257
- **remove the private-home branches from the epic skills (#1276)**
  Every repo is public and homes its epics and queues in its org's .github, so the self-homed-queue and private-home branches go from epic-create, epic-review, epic-implement, epic-retrospective, intake-capture and the skills index. Task 17 of vergil-project/.github#1476. Ref #1240
- **treat an epic drift exit of 1 as an audit problem (#1280)**
