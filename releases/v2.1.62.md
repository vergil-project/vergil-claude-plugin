
# Release 2.1.62 (2026-11-08)

## Bug fixes

- **stop writing the issue body and epic tasks for the request builder (#984)**
vrg-merge-review-request now reads the issue body and derives the epic's open tasks itself (vergil-tooling#4041). Drop the steps that wrote issue-body.md and epic-tasks.json, their table rows, and the --issue-body-file and --epic-tasks-file flags; the epic is read only for the design sources. Ref #982

- **draft a scope change when a deferred-review one-off revival changes scope (#985)**
A revival to one-off can narrow or widen what the item asks for. deferred-review now drafts the change with vrg-ruling draft-scope for the human to post with vrg-scope-change, as intake-review does, pointing to doctrine section 1.7. Revivals to intake or planning need none. Ref #983
