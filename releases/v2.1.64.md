* feat(issue-implement): accept a list of issues and implement them as one batch PR

* fix(issue-implement): state what a batch extraction discards without the tail-of-list rule

* fix(issue-implement): drop the tree-equality check from the batch fold step

Folding an issue's own fixups into its first commit cannot change the final content, and validation and PR CI run on the final branch anyway, so the check guarded against an impossible failure; the epic's design review had deleted it. The one-commit subject check and the conflict handling stay. Ref #1009

* fix(issue-implement): refuse to batch an issue whose single-issue run is under way

Starting a batch ran only Preflight step 6's marker check, so an issue with a single-issue merge review or worktree already in progress could join a batch and have its stale state resumed. Such an issue now fails the start like any other preflight failure. Ref #1009
