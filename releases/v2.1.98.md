## Features

- **name exact plugin and tooling versions when validating a plugin release (#1413)**
  * feat(fixture-run): name exact plugin and tooling versions when validating a plugin release

  The validation task's deployed-version probe now names the exact plugin version and the tooling and actions versions released with it, from the --after tasks' release records, checks the change PR's CI installed that tooling, and checks the agent identity opened and merged the PR after the plugin release. Also reads large CI logs one job at a time. Ref #1373.

  * fix(fixture-run): read plugin release versions from the deployment outcome and the development tasks' records

  A deployment task carries no Released: record of its own, so the probe reads the --after task's Outcome: result and the records on the development tasks it is blocked by. Merge review R1. Ref #1373.
