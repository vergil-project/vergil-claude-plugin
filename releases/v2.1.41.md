
# Release 2.1.41 (2026-10-25)

## Bug fixes

- **enumerate the DoD gate with vrg-epic-audit and stop on failed output (#718)**
The gate documented vrg-gh issue view <owner/repo#N> --json subIssues, which vrg-gh rejects (invalid issue format, exit 1, empty stdout). Make vrg-epic-audit --epic the enumeration command and require running it unpiped with its exit code checked; failed or empty output is ambiguous and stops the gate rather than reading as no open children. Ref #674

- **stop matching vrg-commit in block-protected-branch-work (#719)**
vrg-commit enforces the protected-branch rule itself at run time against the branch it actually executes in, so the hook's cwd guess (reset to the project root under the sandbox) only produced false denies that pushed agents to disable the sandbox. Raw git commit stays guarded as before. Adds regression rows for vrg-commit command shapes and raw git commit on a protected develop branch. Ref #694


## Chores

- **stop tracking generated changelog/releases docs (#720)**
vrg-container-docs stages the generated changelog.md and releases/ into the docs source tree and refuses when a generated path is not gitignored. The managed .gitignore block already ignores these paths; untrack the stale committed copies so the local docs build can run. Ref vergil-project/vergil-claude-plugin#708
