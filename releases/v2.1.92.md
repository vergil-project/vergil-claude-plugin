# Release 2.1.92 (2026-11-24)

## Documentation

- **treat an empty state directory as absent at a session's first round (#1353)**
  A present but empty task state directory, with no trusted record of anything kept there, is now treated as absent at a session's first round, so no confirmation of an empty listing is asked. The directory's real-directory and mode checks and the seal hash still apply. The epic-create and epic-implement restatements are aligned. Ref vergil-project/vergil-claude-plugin#1352
