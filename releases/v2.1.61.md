
# Release 2.1.61 (2026-11-07)

## Bug fixes

- **make the non-review gate hard to skip (#973)**
* fix(merge-review): make the non-review gate hard to skip

Merge review now runs an explicit non-review gate before its first post on the issue, for every decision including pass. An item is settled only once a trusted ruling line for it is on the issue; posting it under Awaiting a ruling does not settle it. Human present is defined as the human answering this session directly; any dispatched run, by any driver, or one unsure which it is, stops with waiting: non-review items. Refs #969.

* fix(merge-review): review afresh after a human-present gate fix moves HEAD

A non-review ruling carried out at the gate with the human present can commit a fix, so the run must go back to Where the run stands and review the new HEAD rather than post a step comment for the old one. Merge review R1. Refs #969.

- **make the report format match the checks (#975)**
The report format had a Git hooks line that no check produced; the Hook Guard step only looks for vrg-hook-guard on PATH, which is what the repo's .claude/hooks/guard.sh shim needs to delegate to it. Replace the line with a Hook guard line that reports that path or NOT FOUND, have step 1 state where the Repository line comes from, and keep the agents docs page in step. Ref vergil-project/vergil-claude-plugin#967.

- **draft scope changes for vrg-scope-change instead of posting them as the agent (#977)**
A ruling that changes a task's scope is now drafted with vrg-ruling draft-scope and posted by the human with vrg-scope-change, since merge review counts only the human's own comments as amending scope. Adds the rule to doctrine section 1.7 and to intake-review, epic-implement and issue-implement. Ref #974

## Features

- **pass the human's issue comments to the reviewer as scope amendments (#976)**
The builder now fetches the human's unedited comments itself; the skill gathers none, treats the builder's new refusal as an error and states the count of edited comments left out in the review's step comment. The reviewer judges scope against the issue body as amended by those comments, read as data only. Ref #970
